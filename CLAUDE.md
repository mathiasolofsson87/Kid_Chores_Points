# Release
When I say "release": run pytest, bump the version in custom_components/kid_chores_points/manifest.json (patch for fixes, minor for features), update CHANGELOG.md, commit, push, create a git tag vX.Y.Z and a GitHub release with notes so HACS picks it up. Ask before pushing if I said "don't push yet".
